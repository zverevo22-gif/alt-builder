# =====================================================================
#  Каталог пользовательских файлов брендинга (BRANDING_MODE=files)
#
#  Структура каталога повторяет корневое дерево будущего образа:
#  любой файл/каталог, положенный здесь, окажется в файловой системе
#  ИНСТАЛЛЯТОРА (стадия install2) под своим путём. Например:
#
#      profile/branding/files/etc/os-release
#          -> /etc/os-release инсталлятора
#      profile/branding/files/usr/share/games/gnome-logo.png
#          -> /usr/share/games/gnome-logo.png
#
#  Ограничения:
#  * файлы попадают в инструментальную часть образа (инсталлятор,
#    Live-загрузка стартует также с него), но НЕ в устанавливаемую
#    систему и не в само Live-ядро squashfs;
#  * чтобы гарантированно изменить /usr/share/... и графические
#    ресурсы УСТАНАВЛИВАЕМОЙ системы, используйте BRANDING_MODE=repo
#    (собственные пакеты branding-<имя>-*) либо BRANDING_MODE=auto
#    со штатными пакетами ALT.
# =====================================================================
