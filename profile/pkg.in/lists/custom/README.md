# =====================================================================
#  Файлы-списки пакетов кастомного состава
#
#  Каждый файл в этом каталоге - список пакетов (по одному имени на
#  строку). Имя файла используется как имя списка в
#  config/packages.conf, например:
#
#      profile/pkg.in/lists/custom/gnome-extra   ->  список "custom/gnome-extra"
#      config/packages.conf: THE_LISTS_EXTRA="custom/gnome-extra"
#
#  Списки передаются сборке только если на них ссылается какая-либо
#  переменная *_LISTS из конфигурации. Внутри списков допустимы
#  макросы @BRANDING@ и архитектурные фильтры (см. docs метапрофиля).
# =====================================================================
